# Clusterfun

A data-exploration tool for browsing, labelling, and analysing image datasets in the browser.

## What you can do

- **Explore** large image datasets in a scrollable grid with similarity search, filtering, and outlier detection.
- **Label** with keyboard shortcuts (1–9), drag-to-tag, and full undo/redo. Label propagation via centroid similarity ("Find more").
- **Plot** any column on the fly — scatter, histogram, violin, embedding maps — with linked brushing.
- **Active learning** in the browser using KNN, centroid, linear, prototype, or MLP heads on cached CLIP embeddings.

## Quick start

```bash
pip install clusterfun
```

```python
import clusterfun as clt
clt.scatter(df, x="x", y="y", media="image_path", color="label")
```

This opens the web UI in your default browser, served from a local Python process.
